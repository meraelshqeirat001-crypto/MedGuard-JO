MedGuard-JO — ملفات التطبيق
================================

محتويات الحزمة:
- index.html: هيكل التطبيق.
- style.css: التصميم المتجاوب.
- app.js: التفاعلات وتكامل Firebase.
- manifest.json: تعريف التطبيق القابل للتثبيت PWA.
- sw.js: Service Worker والتخزين المؤقت للملفات.
- icon-192.png و icon-512.png: أيقونات التطبيق.

التشغيل التجريبي:
1. فك ضغط الملف.
2. ارفع الملفات إلى استضافة HTTPS (مثل GitHub Pages أو Netlify).
3. افتح رابط index.html. عند عدم إعداد Firebase سيعمل التطبيق بوضع تجريبي، وتُحفظ البيانات محلياً على الجهاز والمتصفح فقط.
4. للتثبيت: على Android استخدم خيار Install app / Add to Home Screen. على iPhone افتح الرابط في Safari ثم Share > Add to Home Screen.

إعداد Firebase لتفعيل الحسابات وقاعدة البيانات:
1. أنشئ مشروعاً جديداً في https://console.firebase.google.com/
2. أضف تطبيق Web إلى مشروع Firebase وانسخ إعدادات firebaseConfig.
3. فعّل Authentication > Sign-in method > Email/Password.
4. أنشئ Cloud Firestore Database.
5. استبدل القيم التجريبية YOUR_... في أعلى app.js بإعدادات مشروعك الحقيقية.
6. انشر الملفات مجدداً على استضافة HTTPS.

تنبيه أمني مهم:
- هذه نسخة أولية تعليمية وليست نظاماً طبياً معتمداً.
- قبل تخزين بيانات صحية حقيقية، يجب إعداد قواعد Firestore بحيث يستطيع المستخدم قراءة وكتابة مستند users/{uid} الخاص به فقط، ومراجعة إعدادات الأمان والخصوصية.
- لا تتضمن النسخة تنبيهات دوائية طبية أو توصيات علاجية، ولا تستبدل الطبيب أو الصيدلي.
- بيانات وضع العرض التجريبي محلية على الجهاز وليست قاعدة بيانات سحابية.
